A1 THE PROBLEM

One track, one folder. Music doesn't work like that.

A deep house track can also be mellow, late-night, vinyl-only and festival-tested. A folder can only say one of those.

  1. 01

    Duplicates everywhere

    The same file copied into several folders so you can find it several ways.

  2. 02

    Fragile mental maps

    You remember where things are, until the night before a set.

  3. 03

    Performance software stops short

    DJ software is built to play sets. Library management is an afterthought.

  4. 04

    Media players fall short

    General players lack the tagging depth and search power this needs.

Years of collecting, and the right track is still hard to find.

A2 HOW IT WORKS

Import. Tag as you listen. Search.

  1. IMPORT

    Point it at your folders

    Add any number of library folders. Tracks appear right away with their metadata, and BPM detection runs in the background.

  2. KEEP

    Your folders become tags

    Mark a folder as tag-ish and its name works in search. No re-tagging what you already organised.

  3. TAG

    Select, type, Enter

    Tags are whatever you want: deep, late-night, vinyl, opening-track. Apply several to many tracks at once.

  4. SEARCH

    Combine everything

    #house #high-energy 130returns only the tracks that match every term, as you type.

  5. PREP

    Build the set

    Tabbed playlists sit beside the player, so you can browse one while another keeps playing.

B1 WHAT CARNIVAL DOES

Built for big libraries.

  1. 01

    Freeform tags

    No fixed categories or hierarchies. A track carries as many descriptions as you want.

  2. 02

    Tag-ish folders

    Your existing folder names work as tags in search, and results show which one matched.

  3. 03

    Combined search

    Text, tags and numbers in one bar. Results appear as you type.

  4. 04

    Fast at scale

    Stays responsive with 50,000+ tracks. Browse and search while an import is still running.

  5. 05

    One song, many copies

    The same file in several folders shows up once, with a note of where else it lives.

  6. 06

    Your files stay yours

    Everything runs offline. Carnival never modifies, moves or deletes your files.

A library tool. Not a deck.

Carnival is for preparing a set, not performing one.

  • No streaming services
